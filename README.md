# DestroyCraftMOTD

Плагин для **Paper 1.21.1**, который меняет MOTD (текст в списке серверов) и иконку сервера,
воспроизводя оформление со скриншота — вплоть до точных RGB‑цветов и градиента.

## Что делает

- Строка 1: **DestroyCraft** — градиент `#FB786F → #FFCC66`, жирный курсив · `Версия:` (серый) · `1.21.10` (аква `#55FFFF`)
- Строка 2: `Кланы` (`#BE67F2`) • `Новая броня` (`#FFF967`) • `PvP ранги` (`#FF3459`) • `Статистика` (`#7EFFB9`)
- Иконка сервера (favicon 64×64) в фиолетовой стилистике с логотипом "DS" — лежит в `src/main/resources/icon.png`
- Фейковый максимум игроков в списке (по умолчанию 777, как на скриншоте) без изменения реального лимита из `server.properties`

Все цвета и текст вынесены в `config.yml` — ничего не зашито в коде, можно менять без пересборки.

## Сборка

Нужны JDK 21 и Maven.

```bash
mvn clean package
```

Готовый файл появится в `target/DestroyCraftMOTD.jar`.

### Через GitHub Actions

В репозитории уже настроен workflow `.github/workflows/build.yml`. Просто запушьте проект
в свой GitHub — при каждом пуше в `main` jar будет собираться автоматически, готовый файл
можно скачать во вкладке **Actions → последний запуск → Artifacts**.

## Установка на сервер

1. Скопируйте `DestroyCraftMOTD.jar` в папку `plugins/` вашего Paper 1.21.1 сервера.
2. Запустите сервер один раз — создастся `plugins/DestroyCraftMOTD/config.yml` и `icon.png`.
3. При желании замените `plugins/DestroyCraftMOTD/icon.png` на свою иконку (64×64 PNG,
   можно взять готовую с вашего скрина/логотипа — квадратное изображение без прозрачности лучше всего).
4. Отредактируйте `config.yml`, если хотите поменять текст, цвета или "фейковый" максимум игроков.
5. Примените изменения без рестарта: `/destroymotd reload` (нужны права оператора).

## Настройка текста

Формат — [MiniMessage](https://docs.advntr.dev/minimessage/format.html):

```yaml
motd:
  line1: "<gradient:#FB786F:#FFCC66><b><i>DestroyCraft</i></b></gradient> <gray>•</gray> <gray><i>Версия:</i></gray> <i><color:#55FFFF>1.21.10</color></i>"
  line2: "<i><color:#BE67F2>Кланы</color></i> <white>•</white> <i><color:#FFF967>Новая броня</color></i> <white>•</white> <i><color:#FF3459>PvP ранги</color></i> <white>•</white> <i><color:#7EFFB9>Статистика</color></i>"
```

Можно вставлять любые `<color:#RRGGBB>`, `<gradient:...>`, `<b>`, `<i>`, `<obfuscated>` и т.д.

## Заметки

- Верхняя строчка "Minecraft Server" на вашем скриншоте — это **не MOTD**, а имя сервера,
  которое игрок сам вписал у себя в списке серверов (Minecraft подставляет это имя по умолчанию,
  если сервер не назван). Через плагин это не меняется — так работает клиент игры.
- Значок сети (зелёные полоски) — это пинг игрока до сервера, тоже рисуется клиентом
  и от плагина не зависит.
- Иконка сгенерирована "по мотивам" вашей — с фиолетовым свечением и буквами "DS" — а не
  скопирована пиксель-в-пиксель, чтобы не тиражировать чужую детализированную графику.
  Замените `icon.png` на свою, если она есть у вас в оригинале.
